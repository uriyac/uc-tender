# test-data — נתוני בדיקה

> ⚠️ **חברה פיקטיבית.** כל התוכן כאן הומצא לצורך בדיקות בלבד. אין כאן מידע אמיתי,
> ואף אדם, חברה, לקוח או מסמך כאן אינם אמיתיים.

## אוריה בע״מ (חברת-דוגמה)
פרופיל חברה מלא ומזויף לבדיקת המערכת מקצה-לקצה — העלאת מסמכים, בניית פרופיל,
והרצת מכרזי-דמו דרך צינור הניתוח / חבילת ההגשה.

- `01 - פרויקטים וניסיון/` — קורות פרויקטים לדוגמה
- `02 - אישורים ותקנים/` — אישורים/תעודות מזויפים (ISO, סיווג קבלני, ניכוי מס)
- `03 - פיננסי/` — דוח כספי ומחזור לדוגמה
- `04 - כוח אדם וכשירות/` — קורות חיים של אנשי-מפתח מומצאים
- `05 - לקוחות והמלצות/` — מכתבי המלצה מזויפים
- `06 - מכרזים לבדיקה/` — 3 מכרזי-דמו (A/B/C) להזנה למערכת
- `README-הוראות-בדיקה.md` — הוראות ההרצה הידנית

השתמש בזה כדי לשחזר בדיקה ידנית מלאה בלי להיזקק לנתונים אמיתיים של לקוח.
