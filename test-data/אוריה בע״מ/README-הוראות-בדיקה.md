# ערכת בדיקה — חברת "אוריה בע״מ" (פיקטיבית)

חבילת מסמכים לבחינת מערכת המכרזים מקצה-לקצה, על מנוע **stub**.
כל המסמכים פיקטיביים לחלוטין. המערכת לא מזינה כלום מעצמה — אתה מעלה וממלא.

## מבנה התיקייה (ממוין לפי קטגוריות המערכת)

```
אוריה בע״מ/
├── פרופיל-חברה.md            ← דף עזר להקלדה בהגדרות (לא להעלאה)
├── 01 - פרויקטים וניסיון/     ← 4 מסמכי פרויקט
├── 02 - אישורים ותקנים/
├── 03 - פיננסי/
├── 04 - כוח אדם וכשירות/
├── 05 - לקוחות והמלצות/
└── 06 - מכרזים לבדיקה/        ← 3 מכרזים לעיבוד (לא לאונבורדינג)
```

## סדר הבדיקה המומלץ

### שלב 1 — אונבורדינג / פרופיל החברה
העתק את השדות מתוך [`פרופיל-חברה.md`](פרופיל-חברה.md) לתוך מסך ההגדרות / אונבורדינג.

### שלב 2 — למידת מאגר הידע (העלאת מסמכי חברה)
גרור כל קובץ מהתיקיות `01`–`05` אל הסל התואם במסך העלאת המסמכים.
הצפי (מה שמנוע ה-stub אמור לחלץ):

| תיקייה / קובץ | קטגוריה | מה ייחלץ |
|---|---|---|
| `01/דשבורד-עירוני-חיפה.md` | פרויקטים וניסיון | פרויקט + 6 ממדים + שנה 2023 |
| `01/מוקד-שירות-114-רשויות.md` | פרויקטים וניסיון | פרויקט (114 רשויות, מוקדי שירות, SLA) |
| `01/אינטגרציית-נתוני-רווחה.md` | פרויקטים וניסיון | פרויקט + ממדים + שנה 2024 |
| `01/ניתוח-סקרי-תושבים.md` | פרויקטים וניסיון | פרויקט (50000 תושבים, ניתוח סקרים) |
| `02/אישורים-ותקנים.md` | אישורים ותקנים | ISO 9001, ניהול ספרים, ניכוי מס, סיווג קבלני ג-3 |
| `03/דוח-כספי-ומחזור.md` | פיננסי | (כיסוי קטגוריה) |
| `04/צוות-ואנשי-מפתח.md` | כוח אדם וכשירות | (כיסוי קטגוריה) |
| `05/המלצות-לקוחות.md` | לקוחות והמלצות | (כיסוי קטגוריה) |

יעד: **מד מוכנוּת = 100%** (כל 5 הקטגוריות), **4 פרויקטים**, **~4 אישורים**.

### שלב 3 — עיבוד מכרזים (3 תרחישים)
העלה כל מכרז מתיקיית `06 - מכרזים לבדיקה/` בנפרד (במסך המכרזים, לא באונבורדינג):

| מכרז | מטרת הבדיקה | הצפי על stub |
|---|---|---|
| `מכרז-A-דשבורד-עירוני.docx` | התאמה ישירה | ציון התאמה גבוה, תנאי-סף ירוקים, טיוטה בביטחון גבוה |
| `מכרז-B-מוקד-106.docx` | ניסיון סמוך (גמישות) | ציון בינוני + פערים. *על claude* אמור להופיע גשר-גמישות |
| `מכרז-C-תשתיות-מים.docx` | מלכודות ודגלים אדומים | הרבה דגלים אדומים, פער תנאי-סף (15 שנות ניסיון > 12), ציון נמוך |

## מה בכוונה *לא* נבדק כאן
**גמישות מכרזית (גשר לניסיון סמוך)** — קיים רק במנוע claude. על stub ההתאמה היא
חפיפת-מילים בלבד (`relevance` תמיד `direct`). מכרז B בנוי כך שיהיה מוכן לבדיקה הזו
כשתחובר API.
