### B05 — Tender Detail / Go-No-Go (S07)
**סטטוס:** ✅ הושלם (2026-07-25) | route: /he/tender/analysis — Match Score, Go/No-Go, ניתוח פערים, כרטיס מתחרים-בקרוב
**פרומפט בסיס:**
```
בנה מסך ניתוח מכרז + Go/No-Go decision.
- Header: שם מכרז, מגיש, deadline (עם countdown)
- Match Score: ויז'ואל ברור — gauge או circle — לא רק מספר. הסבר קצר מתחת.
- Gap Analysis בשלושה סקשנים:
  ✅ עומדים ב: (רשימה ירוקה)
  ⚠️ פערים: (רשימה צהובה עם "מה לעשות")
  ❌ לא עומדים: (רשימה אדומה — אם רלוונטי)
- שני כפתורות ראשיים: "צור טיוטה" (ירוק) | "ארכב — No Go" (אפור)
- אל תגע בשאר הניווט
```

## Sprint 6 — מודיעין מכרז (מניתוח BIDO)
**מטרה:** להעלות את מסך הניתוח (S07) מעל bido.ai — סיכום מובנה + דגלים אדומים.
**מקור:** `01-research/COMPETITOR-BIDO.md`

### B10 — סיכום מכרז + דגלים אדומים (S07) 🔴 עכשיו
**סטטוס:** ✅ הושלם — כרטיס סיכום + תנאי-סף מוצלבים לפרופיל + דגלים אדומים (stub+claude+UI, אומת בדפדפן)
```
בראש מסך הניתוח, כרטיס "סיכום מכרז": היקף · משך · ערבות · מועד · סיווג נדרש.
מתחת: "בדיקת תנאי סף" — הצלבת דרישות מול פרופיל החברה (נדרש N שנים → יש לכם M ✓/⚠).
סקשן "דגלים אדומים": סעיפי פסילה, קנסות, מלכודות (הנחה מעל X% תיפסל, וכו').
מנוע: checkThresholds (קיים) + checkRedFlags (חדש) + parseTender מובנה. אפס-הזיות נשמר.
```

### B11 — חילוץ מכרז מובנה + הצלבה לפרופיל 🔴 עכשיו
**סטטוס:** ✅ הושלם — parseTender מחלץ ערבות/סיווג/מחזור/משך/מועד; נשמר על ה-tender ומוצג בכרטיס הסיכום
```
שדרג parseTender לחלץ שדות מובנים: code, issuer, deadline, guarantee (ערבות),
classification (סיווג קבלני), min_turnover (מחזור מינימלי), duration (משך).
נשמרים על ה-tender. מוצגים בכרטיס הסיכום ומוצלבים מול פרופיל החברה.
```
